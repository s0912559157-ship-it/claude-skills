# Subagent 交辦格式

每份分析（市場／國際局勢／AI）都要另開一個 subagent，做「先各自獨立，再交流」。
主分析者在交辦前，**先把自己的第 1 輪寫完存檔**，不要把自己的結論放進交辦內容。

## 第 1 輪交辦（獨立分析）

交給 subagent 的內容只能有：
1. 今天的晨間簡報原文（或相關段落），以及資訊截止時間（台北時間）。
2. 對應的框架檔全文（`references/` 裡那一份；AI 另附國際框架，因為 AI 框架以它為底）。
3. 共用追蹤表目前的內容（`references/tracker-template.md` 格式）。
4. 要它交回的格式（下方）。

**不要給**：主分析者的候選解釋、結論、偏好的說法。

要它交回（存成 `agent-round1.md`）：
- 每則新聞：選哪張題型卡／放哪個分級，理由一句。
- 候選解釋（至少兩個互相競爭的），各自的證據與**證據缺口**。
- 判別條件：看到什麼資料會支持 A、削弱 B。
- 晨間簡報裡需要校正的說法（日期、程序階段、來源性質）。
- 追蹤表要新增或更新的項目。

## 第 2 輪交辦（交換與雙向挑戰）

雙方第 1 輪都存檔後才進行。交給 subagent：主分析者的 `main-round1.md`。

要它交回（存成 `agent-round2.md`）：
- 對主分析者每個主要主張：同意／不同意／證據不足，並說明。
- **最強反對意見**：每個核心主張一條，針對對方最後留下的結論（不是已撤回的初版），寫清楚它如果成立會推翻哪個主張。
- 自己第 1 輪有哪些要修正。

主分析者也要對 agent 第 1 輪做同樣的挑戰，寫進 `main-round2.md`。

## 收斂

- 把最強反對意見與它的**去向**（排除／未排除／改寫結論）寫進簡報。
- 雙方意見一致，**不算多一份證據**；只能說「兩位分析者看法相同」。
- 沒有共同主線時，直接寫「沒有共同主線」，不硬湊。
