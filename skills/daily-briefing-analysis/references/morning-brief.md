# 每日早晨簡報（晨間簡報）的指令

這份是排程任務「每日早晨簡報」（週一到週五 07:45 台北時間）用的指令，改寫成不依賴特定電腦的版本。
每天分析流程的第 1 步由 agent 照這份自己產生；排程任務也用這份。

## 前提

- 用內建的 morning skill（`anthropic-skills:morning`）產生；沒有這個 skill 就照下面的段落自己整理。
- 能連的來源才用，連不到的略過並在簡報末尾註明，不要因此停下來：Google Calendar、Gmail、Slack、網路搜尋。
- 不使用也不提 Microsoft 365／Outlook／Teams。
- 若是無人值守的排程執行：不要問問題、不要顯示連接器建議卡，直接產生。

## 指令

整份簡報用繁體中文（台灣用語）。使用者的時區是 Asia/Taipei（UTC+8）。（姓名：<填入你的名字>）

蒐集來源：
- 今天的行事曆（Google Calendar）。
- 緊急、等使用者回覆的信件（Gmail）。
- 過去約 24 小時內提到使用者、私訊使用者或需要使用者回覆的 Slack 訊息。
- 使用者自己的待辦筆記：有記憶檔 `/areas/morning-brief-notes.md` 時讀取（memory_read）。列在今天日期（台北時間）底下的每一項，都是使用者自己寫的待辦，放在「需要你處理」最上面，用使用者自己的字（來源寫：你自己記下的待辦）。有時間的項目（例如今晚開會）也要反映在當天行程。其他日期的項目忽略。檔案不存在或今天沒有項目就略過，不用提。

段落：
- **追蹤的新聞**：一個區塊、四個子分組，每組 2–3 則，取過去約 24 小時內的新聞，用網路搜尋找，每則附原始來源連結：
  - AI 與科技
  - 台灣財經（包含最新的台股加權指數收盤）
  - 設計與創意產業
  - 國際要聞

## 交付

1. 存成 HTML：`morning-brief-YYYY-MM-DD.html`。
   - 存到 SKILL.md 第 0 步的使用者資料夾：`HOME_DIR/YYYY-MM-DD/morning-brief-YYYY-MM-DD.html`；日期資料夾不存在就建立。
   - 找不到使用者資料夾：不要寫進使用者設備，直接在對話裡交付，並請使用者開一個資料夾。
2. 有 Artifact 工具時，也發佈成 Artifact（每天更新同一個標題為「每日簡報」的 Artifact）。
3. 最後用繁體中文送出一句當天摘要。

## 與分析流程的銜接

晨間簡報產生後，若使用者要「讀取今日簡報」，就接著 SKILL.md 的第 1 步：以這份 HTML 當作今日簡報。
