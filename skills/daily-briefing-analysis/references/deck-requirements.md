# 簡報規格（每份都要符合）

## 做簡報之前：先和使用者討論

最好的簡報，是和使用者討論過、照使用者的問題與補充做出來的。所以順序固定是：

1. 給使用者今日簡報的摘要。
2. 三份分析（雙向挑戰）完成後，**先不要做簡報**，把重點和你的暫定判斷用幾句話告訴使用者，
   並**主動問使用者 3–5 個問題**，例如：
   - 哪則想深入、哪則可以略過。
   - 有沒有看不懂的名詞（主動點出你覺得可能需要解釋的）。
   - 對你的暫定判斷有沒有不同看法、想追問的因果。
   - 有沒有使用者自己知道、簡報沒寫到的資訊。
3. 依使用者的回答補充、修正，必要時再問一輪。
4. 使用者說可以做了（或明確說「直接做」）才做簡報。使用者說直接做時，在封面註明「未經使用者討論」。

使用者在討論中問的每個問題，都要在**做簡報之前**回答完；簡報裡照樣收錄（`ask=True` 的「你問」頁），
但簡報不是用來第一次回答問題的地方。

## 每份簡報必備

1. **一句話結論**：封面標題就是結論；結論頁再寫一次，附信心程度與一句理由。信心只能寫「高」「中」「低」其中一個，不寫「中低」「中偏高」這類組合。
2. **追蹤表**：一頁，列這份簡報引用到的追蹤項目、狀態、下次檢查或到期日（寫明時區）。狀態用語見 `tracker-template.md`。
3. **來源清單**：最後一頁。格式：
   - 一列只寫一個來源、一種性質（原始／轉述／【僅標題】）。
   - 每列寫去向（採用／排除／待核對）與取得時間（寫明時區）。
   - 正文說「已核對 X 官方（原始文件）」時，X 的原始文件必須列在清單上。
   - 每頁頁尾仍要寫該頁來源。
4. **影響與觀察點**：每一則新聞至少一行，不能留空；判斷不了就寫「尚無法判斷」加理由。

## 頁序（固定）

封面 → 正文（各則新聞、分析、雙向挑戰紀錄） → **結論頁** → **追蹤表** → **來源清單（最後一頁）**。

## 時間口徑

- 時序論證用到的事件，寫「公開時間」並寫明時區；公開時間和事件發生日不同時，兩個都寫。
- 封面的資訊截止時間 ＝ 最後一次查證的時間。來源的取得時間不得晚於截止時間；截止後才拿到的材料，要嘛把截止時間往後改，要嘛不用。

## 每份簡報都是完整的資料來源

- 使用者會單獨讀任何一份簡報，所以每份都要能獨立看懂。
- 同一件事出現在不止一份簡報時（例如一則 AI 新聞也牽動股市），每份都要把和它相關的內容完整寫出，包括對市場的影響；**不寫**「見市場簡報」這類轉介。內容重複沒有關係。
- 不同簡報之間互相引用，不算多一份證據（見 `tracker-template.md`）。

## 其他規則

- 頁數沒有上限。每頁閱讀負擔輕、一眼可掃；寧可多頁也不要塞字。不需要問題目錄頁。
- 必須涵蓋所有討論項目，包括使用者的每個追問與名詞解釋，不可只摘要。
- 封面寫資訊截止時間（台北時間）。
- 只看得到標題的付費來源：可以當線索，不能單獨當證據；簡報上標【僅標題】。
- 國際、AI 頁面依框架加刊出標籤（如【轉述】【程序中】）。

## 做完之後

- 附上 PDF 給使用者看，同時附上當天的自評分數（四項各一個數字）。
- **要不要存檔由使用者決定**。使用者回「可以」或說要存，才把 PDF 存進使用者資料夾的當天日期資料夾；沒說就不存。
- 簡報腳本、HTML 等中間檔只能放暫存區，當天結束前刪掉（見 SKILL.md 第 0 步）。
