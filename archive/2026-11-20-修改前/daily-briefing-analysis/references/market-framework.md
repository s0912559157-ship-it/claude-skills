## 一、五個步驟

| 步驟 | 必要產出 |
|---|---|
| **1. 定問題、截止時間與口徑** | 寫明要解釋哪段變動、資訊截止時間，以及關鍵資料的時間、口徑和核對狀態 |
| **2. 列現象與競爭解釋** | 列出待解釋的現象和它違反的預期；提出至少兩個有實質差異的解釋，並說明能否同時成立 |
| **3. 做能分辨解釋的檢查** | 用當下拿得到的資金、相鄰資產或族群、個股資料，記錄它支持、削弱或分不出哪個解釋 |
| **4. 雙向挑戰與暫定判斷** | 解釋的排序（或「無法排序」）、關鍵未知、實際分歧，以及針對最終主結論最強的反對意見和它的去向 |
| **5. 預約更新與撤回** | 下次更新要用的資料和取得時間，以及事先寫好的支持觀察、重查警報和撤回條件；保存這次的判斷 |

### 各步驟注意事項

**1. 定問題、截止時間與口徑**
- 要解釋的變動要拆段，例如開盤跳空和盤中走勢分開看。
- 每筆資料標三個時間：事件時間、首次公開時間、資料所屬期間。不知道就寫「未知」。
- 兩個市場的週資料期間重疊時，不能拿來推先後因果。

**2. 列現象與競爭解釋**
- 不叫「抓矛盾」，改叫「找待解釋的現象」。每個現象都要問：它違反了什麼預期？這個預期有依據嗎？
- 如果預期本身沒有依據（例如假設殖利率和股價一定反向），就不算矛盾，不列入。
- 至少要有兩個解釋，而且這兩個解釋預測的結果要不一樣。

**3. 做能分辨解釋的檢查**
- 先問：這項比較能不能分辨兩個解釋？如果兩個解釋都預期同一個結果，看到這個結果也判斷不了。
- 結果分四種：沒做、做了但分不出來、支持、削弱。只寫了方法沒有結果，就算「沒做」。
- 追資金時，分清存量（部位水準）、流量（買賣超）、價格和推論出的動機。買超先看買的是什麼。
- 族群、個股層要看跟問題有沒有關係：必要但缺資料就標「未完成」並縮小結論範圍；無關就標「不適用」。

**4. 雙向挑戰與暫定判斷**
- 主分析者挑戰 agent，agent 也要對主結論提出最強的反證。
- 可以結論為「目前還無法排序」。
- 最強的反對意見要針對**最後留下的主結論**，不能只駁倒已經放棄的初版說法。

**5. 預約更新與撤回**
- 撤回條件要在看到驗證結果**之前**寫好。
- 分清兩種條件：
  - **重查警報**：碰到就重查，不自動代表判斷錯了。
  - **撤回條件**：成立就撤回該主張。可以由幾項觀察組合而成。
- 分清兩種情況：**當初的判斷錯了**，和**後來情勢變了**。
- 寫不出撤回條件的主張，要先縮小主張範圍。

## 二、全程規則

1. **先各自獨立，再交流**：雙方先各自提出候選解釋、證據缺口和判別條件，再看對方的結論。雙方意見一致，不算多一份證據。
2. **證據表跟著主張建立**：一提出主張就填，不等到最後補。欄位：主張｜事實或推論｜來源｜資料時間｜核對狀態｜若錯會如何改變結論。
3. **每個來源都要有去向**：進入分析的來源標「採用／排除／待核對／待判斷」並寫理由。沒核對的資料不能當成已確認的前提，也不能當正式門檻的依據。
4. **競爭解釋用同一套標準**：都檢查時序、機制證據、相對表現和不利的觀察。跟某個解釋不衝突，不代表它勝出。資料不足的一方，不能因為另一方還沒被證實就自動勝出。
5. **資料概念要清楚**：分清存量、流量、價格和推論出的動機。
6. **未知問題當下分級**：會改變主結論／影響次要歸因／只補背景。第一級沒解決時，主結論維持待驗證，但可以縮小成資料足以支持的結論。
7. **反對意見要寫明去向**：寫下最強的版本，再寫是被哪項證據駁回、為什麼暫不改變排序，或還缺什麼資料。不能把「沒採納」寫成「已排除」。
8. **事先約定怎麼改判**：門檻要附依據；分清重查和撤回；不能讓所有不利結果都只換來「再觀察」。
9. **按完成條件停止**：不規定輪數，也不規定一定要有分歧。核心主張檢驗完、反對意見有了去向、剩下的未知和更新時間都清楚，就可以結束這一輪。
10. **更新時保留舊版本**：標明哪些主張升級、降級或撤回。不能把盤後才知道的資訊，寫成盤中就已經知道。

## 三、狀態標記

| 類型 | 選項 |
|---|---|
| 證據狀態 | 未核對／已核對／有衝突 |
| 主張狀態 | 待驗證／目前較受支持／無法區分／已撤回 |
| 檢查結果 | 沒做／做了但分不出來／支持／削弱 |
| 層級狀態 | 已完成／必要但缺資料／不適用 |

> 「定案」只代表這一輪紀錄寫完，不代表歸因已經確證。

## 四、為什麼這樣改

| 原框架的問題 | 這次發生的情況 | 修訂 |
|---|---|---|
| 先抓矛盾，再對齊時間 | 殖利率對 S&P、外資買超對台幣這兩個「矛盾」，後來證實是錯誤預期 | 時間和口徑放第 1 步；「抓矛盾」改成「找待解釋的現象」 |
| 只有一個解釋 | 殖利率的說法被推翻後，換成另一個同樣沒驗證的說法，結論反而寫得更篤定 | 強制要有競爭解釋，並用同一套標準檢驗 |
| 因果鏈沒逐環標事實或推論 | 「動能耗盡」只從先漲後跌反推出來 | 改用主張與證據表，全程填寫 |
| 相鄰資產驗證只寫了方法 | 匯率比較沒做，卻被當成已經完成 | 結果分四種，沒有結果就算「沒做」 |
| 假設時間戳放在第 7 步 | 時間標記前後矛盾（寫「11/13 單日」，卻沒有當天的資料） | 併入全程的證據表 |
| 證偽條件沒有依據，也混了兩件事 | 門檻沒有推導；「指數站回」被當成證明下跌是雜訊 | 分成重查警報和撤回條件，並分清當初判斷錯了和後來情勢變了 |
| 未解問題並列 | 9 個問題沒分輕重，結論照常寫成定論 | 未知當下分級 |
| 來源沒有去向 | FT 回任報導只列在來源清單，正文沒用到 | 每個來源都要標去向 |
| 只有單向挑戰一輪 | 五個挑戰都由主分析者提出，agent 全部同意 | 雙向挑戰；寫下最強的反對意見和它的去向 |
