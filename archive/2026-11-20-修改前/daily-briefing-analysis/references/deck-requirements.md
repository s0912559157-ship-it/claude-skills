# 簡報規格（每份都要符合）

## 做簡報之前：先和使用者討論

最好的簡報，是和使用者討論過、照使用者的問題與補充做出來的。所以順序固定是：

1. 給使用者今日簡報的摘要。
2. 三份分析（雙向挑戰）完成後，**先不要做簡報**，把重點和你的暫定判斷用幾句話告訴使用者，
   並**主動問使用者 3–5 個問題**，例如：
   - 哪則想深入、哪則可以略過。
   - 有沒有看不懂的名詞（主動點出你覺得可能需要解釋的）。
   - 對你的暫定判斷有沒有不同看法、想追問的因果。
   - 有沒有使用者自己知道、簡報沒寫到的資訊。
3. 依使用者的回答補充、修正，必要時再問一輪。
4. 使用者說可以做了（或明確說「直接做」）才做簡報。使用者說直接做時，在封面註明「未經使用者討論」。

使用者在討論中問的每個問題，都要在**做簡報之前**回答完；簡報裡照樣收錄（`ask=True` 的「你問」頁），
但簡報不是用來第一次回答問題的地方。

## 每份簡報必備

1. **一句話結論**：封面標題就是結論；結尾頁再寫一次，附信心程度（高／中／低）與一句理由。
2. **追蹤表**：一頁，列這份簡報引用到的追蹤項目、狀態、下次檢查或到期日（寫明時區）。
3. **來源清單**：最後一頁，列這份簡報用到的所有來源，每個標明：原始／轉述／【僅標題】、取得時間。
   每頁頁尾仍要寫該頁來源。

## 其他規則

- 頁數沒有上限。每頁閱讀負擔輕、一眼可掃；寧可多頁也不要塞字。不需要問題目錄頁。
- 必須涵蓋所有討論項目，包括使用者的每個追問與名詞解釋，不可只摘要。
- 封面寫資訊截止時間（台北時間）。
- 只看得到標題的付費來源：可以當線索，不能單獨當證據；簡報上標【僅標題】。
- 國際、AI 頁面依框架加刊出標籤（如【轉述】【程序中】）。

## 做完之後

- 附上 PDF 給使用者看，同時附上當天的自評分數（四項各一個數字）。
- **要不要存檔由使用者決定**。使用者回「可以」或說要存，才把 PDF 存進使用者資料夾的當天日期資料夾；沒說就不存。
- 簡報腳本、HTML 等中間檔只能放暫存區，當天結束前刪掉（見 SKILL.md 第 0 步）。
