# 國際簡報分析框架（修訂版）

- 修訂日期：2026-11-16

---

## 核心原則
- **發生了什麼**：可以並列。
- **為什麼發生**：要比較競爭解釋。
- **彼此有沒有關聯**：要另外舉證。
- **今天沒有共同主線**：這是合法的產出。

---

## 一、常駐分析底稿

底稿保留分析過程，簡報頁面只放讀者需要的結果。底稿照「議題 → 事件 → 主張 → 待檢核」建立關聯，不用每天重抄。

| 欄位 | 必要內容 |
|---|---|
| **議題** | 編號、範圍、上次摘要；議題名稱不能預設因果 |
| **關鍵證據／指標** | 用來檢驗哪個主張、多久更新或由什麼事件觸發、資料截至何時；缺了會限制哪些判斷 |
| **事件與識別** | 日期、地點、行為者等足以辨認事件的資訊；標明是新事件、舊事件更新，還是無法辨識 |
| **主張與證據** | 主張內容、類型、來源鏈、核對範圍與狀態；事件時間、首次公開時間、資料所屬期間，不知道就註明 |
| **程序階段**（適用時） | 誰有權決定、目前走到哪一步、還要誰批准或執行 |
| **判斷與更正** | 主張狀態、關鍵未知、最強的反對意見和它的去向；更正保留舊版本，並連到受影響的後續判斷 |
| **選題與篇幅** | 深讀／短訊／只更新追蹤，加一句理由；區分「值得追」和「證據足夠深入分析」 |
| **待檢核** | 對應哪個主張、觸發條件、要查什麼資料、支持和撤回的規則、上次檢核和下次檢核的時間 |

只更新**今天相關、已經到期、或有重大更正**的項目。另外照常掃描新事件，不讓舊的追蹤清單決定選題。

## 二、每日四步

| 步驟 | 必要產出 |
|---|---|
| **1. 截止與檢核** | 寫明資訊截止時間；處理到期的觀察點和重大更正；記錄主張怎麼變化、哪些檢核沒做完、缺了哪些證據 |
| **2. 選題與證據** | 暫定每則的分級並寫理由；確認來源歸屬、事件識別和程序階段；證據不足就限制分析或降級 |
| **3. 解釋與連結** | 只要提出因果、動機或跨事件關聯，就比較實質不同的解釋，交代目前能判斷什麼，並寫出最強的反對意見和它的去向 |
| **4. 影響與觀察點** | 區分已經發生和預期的群體影響；需要時評估市場通道；指定下次檢核要用的資料、觸發條件和改判規則 |

- 第 3 步只在提出因果、動機或關聯時才做。
- 第 4 步可以寫「影響尚無法判斷」。
- 資料不足時：刊登來源歸屬清楚的短訊，或只更新追蹤表，不為了填滿欄位而推測。

## 三、出版檢查清單

- [ ] **時間與識別**：寫了資訊截止時間；分得出新事件和舊事件更新；數字標了時間、單位和範圍；跨日比較前先對齊口徑。
- [ ] **來源與歸屬**：分清當事方、原始報導者、轉載者和作者推論；多次轉載不算多份獨立證據。
- [ ] **標題與標籤**：標題不比正文確定；說法保留歸屬；標籤不超出實際核對的範圍，也不能拿來替誇大的文字背書。
- [ ] **程序與行動**：發言、提案、審查、批准、生效、執行不混用；公開立場不等於真實動機。
- [ ] **分析與主線**：短訊也不能偷偷加入歸因；跨事件關聯要另外舉證；整份簡報如果有總主線，主線本身要接受雙向挑戰。
- [ ] **反對意見**：針對最後保留的核心主張，寫明最強的反對意見是被駁回、還沒排除，還是為什麼暫時不改變排序；雙方意見一致不算多一份證據。
- [ ] **影響與篇幅**：重要性不以有沒有市場通道為前提；不把不同群體的得失合併成國家整體的得失；素材多寡不直接決定篇幅。
- [ ] **市場連結**（選填）：分清已觀察到的影響、可能的機制和缺口；第一環成立不代表整條鏈成立；同一個事件不代表同一個歸因。
- [ ] **停止展開**：資料不足就停在短訊或只更新追蹤；缺指標只限制依賴該指標的分析，不影響刊登短訊。
- [ ] **更正與更新**：更正延續到後續版本；到期的觀察點都有處理；分清「當初判斷錯了」和「後來情勢變了」，不事後改寫原本的預測。

## 四、底稿狀態詞表

| 類別 | 選項 |
|---|---|
| 主張類型 | 事件陳述／某方說法／分析推論／價值判斷 |
| 證據核對 | 未核對／部分核對／已核對（每次註明核對範圍，可另加「有衝突」） |
| 主張狀態 | 待驗證／目前較受支持／無法區分／已撤回 |
| 本次判斷變化 | 支持增加／維持／削弱／撤回／無法裁決（原主張不夠明確時直接註明） |
| 檢核工作狀態 | 未到期／到期未檢核／檢核中／本輪已檢核（「已檢核」的結果可以是無法裁決） |
| 選題層級 | 深讀／短訊／只更新追蹤 |
| 影響狀態 | 已觀察／預期／尚無法判斷 |
| 市場通道 | 已觀察到影響／可能通道待驗證／無明確通道／尚未評估 |

> 「主張狀態」說的是主張被支持的程度，「檢核工作狀態」說的是工作做到哪裡，兩者不能混在一起。
> 價值判斷要公開評價標準，不硬套因果的證偽條件；事實和因果主張要有對應的更正或撤回規則。

## 五、刊出標籤詞表

標籤放在標題前，順序是「來源與證據 → 事件階段或更新」，最多兩個，不是每則都要有。

| 標籤 | 使用條件 |
|---|---|
| 【轉述】 | 這次的依據是間接報導，原始材料還沒直接核對 |
| 【單方說法】 | 核心內容只來自一方，沒有獨立確認；標題仍要寫出是誰說的 |
| 【說法衝突】 | 已經拿到互相矛盾的說法，還沒釐清；不代表各方證據一樣強 |
| 【待核對】 | 核心內容的依據或核對範圍不明，上面幾個標籤又說不清楚時才用；不能拿來當刊登低品質內容的許可 |
| 【程序中】 | 內容涉及還沒完成的決策程序；正文要交代目前階段和剩下的步驟 |
| 【更新】 | 同一事件有重要的新資訊，不代表之前的版本有錯 |
| 【更正】 | 之前刊出的內容有錯；正文要寫出更正了什麼、影響哪些判斷 |
| 【分析】 | 標題的核心是作者的解釋；必須先通過競爭解釋和反向挑戰 |

> **不使用籠統的【已核對】標籤**。核對狀態放在底稿，必要時在正文具體寫「已核對官方文件」或「已核對發言原文」，讓讀者知道確認的到底是什麼。
